IAST, or Interactive Application Security Testing, is a security testing method that analyzes an application while it's running, using real-time monitoring and instrumentation to identify vulnerabilities.
How to scan an application:
  • Click the "Scan in runtime" button and confirm it's starting
  • Start browsing the application you are scanning, e.g. click on different links, submit forms, etc.
  • Once completed open IAST scanner and stop the scan
  • Check the result
